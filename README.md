# hellbound

#  Brackeys Game Jam 2026.2 theme was Trust No one 

# Plan
We had previous experience developing games under tight time constraints, so this time we set realistic goals from the beginning.

We had a couple of ideas, but based on our experience with previous projects, we quickly dropped the more ambitious plans and focused on making one simple idea a reality.

We built a quick MVP of the game we had in mind, then spent the remaining time adding details such as music, models, animations, and VFX to make the game feel more polished and complete.

# Game state
Almost everything is done! Of course, there are still some problems, especially with the cutscenes. We didn't really know how to make them properly, and with the limited time available, we couldn't afford to spend too long figuring them out.

Instead, we came up with quick tricks and custom solutions to work around those problems. If you look closely at the game, you can probably find little shortcuts like this everywhere.

Despite that, this has been one of our most satisfying game jams. For this event, we managed to keep the mechanics focused and put most of our effort into turning them into a polished game for others to play and rate.
